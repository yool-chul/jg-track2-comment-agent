## 설치 · 실행 (Mac, 10분)

준비물: **Google Chrome**, **uv**(Python 패키지 관리자 — Python 3.12도 알아서 받습니다)

```bash
brew install uv                      # 또는: curl -LsSf https://astral.sh/uv/install.sh | sh
git clone https://github.com/yool-chul/jg-track2-comment-agent.git
cd jg-track2-comment-agent
uv run python src/server.py          # 처음 실행 때 패키지를 설치하고, 브라우저에 http://127.0.0.1:8080 이 열립니다
```

### 크롬 프로필 유튜브1~3 연결

크롬은 평소 쓰는 기본 프로필의 자동 제어를 막기 때문에, 대시보드 폴더 안 `profiles/<이름>` 폴더를 프로필로 씁니다. **처음 한 번만** 아래 명령으로 일반 크롬 창을 열어 해당 구글 계정으로 유튜브에 로그인한 뒤, 그 창에서 `Cmd+Q`로 종료하세요.

```bash
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --user-data-dir="$PWD/profiles/유튜브1" --no-first-run https://www.youtube.com/
# 유튜브2 · 유튜브3도 이름만 바꿔 같은 방법으로
```

로그인한 프로필만 대시보드의 프로필 목록에서 고를 수 있고, 폴더가 없는 프로필은 '설정 안 됨'으로 표시됩니다. 대시보드는 이 폴더를 크롬에 넘겨 열기만 하고, 쿠키 · 비밀번호 파일을 읽지 않습니다.

### AI 키 (선택)

키가 없어도 `drafts/`에 미리 만든 초안으로 동작합니다. 키를 넣으면 초안이 없는 새 영상도 그 자리에서 초안을 만들고, [초안 다시 만들기]를 쓸 수 있습니다.

```bash
cp .env.example .env                 # .env에 ANTHROPIC_API_KEY=... 입력 (저장소에 올라가지 않음)
```

## 설정 — `config.yaml`

| 항목 | 내용 |
|---|---|
| `profiles` | 크롬 프로필 이름 (폴더: `profiles/<이름>`) |
| `channels` | 불러오기 · 게시를 허용하는 우리 채널 5개 |
| `test_videos` | 개발 중 게시 테스트를 한 본인 테스트 영상 |
| `test_only` | `true`면 본인 테스트 영상에만 게시 (개발 · 시연 준비용 안전장치). 기본 `false` |
| `comment` | 공백 포함 120자 이하 · 공백 제외 40자 이상, 브랜드 '운명원' 정확히 1회 |
| `limits` | 하루 게시 상한 (기본 10개) |

## 하는 일 · 하지 않는 일 (안전 규칙)

| 규칙 | 지키는 방법 (코드 위치) |
|---|---|
| 쿠키 · 비밀번호 · 브라우저 저장 정보를 읽거나 저장하지 않음 | 프로필 폴더를 크롬에 넘겨 열기만 함 (`src/poster.py`) |
| AI 키를 화면 · 로그 · 외부로 내보내지 않음 | `.env`에서만 읽고, 화면에는 설정 여부(true/false)만 보냄 (`src/server.py`) |
| 우리 채널 영상(+ 본인 테스트 영상) 외의 페이지를 열지 않음 | 게시 전 운영 규칙 통과 후 그 영상 페이지 하나만 엶. 직접 입력한 링크는 채널을 확인해 허용 채널이 아니면 막음 (`src/guard.py`, `src/server.py`) |
| 댓글 작성 외의 동작(구독 · 좋아요 · 설정 변경)을 하지 않음 | 누르는 것은 댓글 창 · 게시 버튼뿐 (`src/poster.py`) |
| 유튜브와 AI 서비스 외에 데이터를 보내지 않음 | 서버는 `127.0.0.1`에만 열리고 화면 자원은 모두 로컬(외부 CDN 없음). 네트워크는 youtube.com · Anthropic API만 |
| 대시보드 폴더 밖 파일을 읽지 않음 | 모든 경로가 프로젝트 폴더 기준 (`profiles/`, `drafts/`, `data/`) |
| 영상당 댓글 1개 · 하루 상한 · 허용 범위 · 기록 | 서버가 게시 전에 반드시 검사하고 위반은 '차단'으로 기록 (`src/guard.py`, 테스트 `tests/test_guard.py`) |
| 댓글 규칙 | 글자 수 · 운명원 1회 · 링크 · 해시태그 · 지어낸 이용 후기 표현을 검사하고 어기면 최대 3번 다시 씀 (`src/drafter.py`) |

## 그 밖의 명령

```bash
uv run python src/make_drafts.py 3   # 채널별 최신 3개 초안을 drafts/에 미리 생성 (인자 없으면 15 = RSS 전체, AI 키 필요)
uv run pytest                        # 운영 규칙 · 링크 해석 · 장면 미리보기 테스트
```
