# 대시보드 구현 현황 (v1)

> 기준: 원본 과제 문서 — 수정 과제(시연영상만 제출)는 2026-10-16 17시 이후 확인 예정 · 설계: [[adr-001-python-uv-claude-stack]] · 근거: [[spike-01-게시-흐름]], [[spike-02-댓글-프롬프트]]

## 실행

```bash
uv run python src/server.py            # http://127.0.0.1:8080 이 브라우저에 열린다 (--no-browser로 끔)
uv run python src/make_drafts.py 3     # 채널별 최신 3개 초안을 drafts/에 미리 생성 (인자 없으면 15 = RSS 전체)
uv run pytest                          # 운영 규칙 테스트
```

## 구성

| 파일 | 역할 |
|---|---|
| `config.yaml` | 프로필 · 허용 채널 5개 · 본인 테스트 영상 · 글자 수 · 하루 상한 |
| `src/server.py` | FastAPI, 127.0.0.1 전용. 영상 불러오기 · 링크 추가 · 초안 · 게시(백그라운드 작업 + 진행 상태) · 기록 API |
| `src/static/` | 화면: 메인(불러오기 · 검색 · 필터(댓글 · 초안 · 실영상/테스트) · 카드 목록, 댓글 달림 여부) → 상세(영상 플레이어 · 초안 · 댓글 달기 / 댓글 단 영상은 기록만) · 전체 기록 탭. 빌드 없음, 외부 CDN 없음, 라이트/다크 |
| `src/youtube.py` | RSS 최신 영상, 링크 → 영상 ID, 영상 공개 정보(채널 확인), 자막(상태: ok · none · blocked), 장면 미리보기(스토리보드), 인기 댓글 |
| `src/drafter.py` | 프롬프트 v3(자막 없으면 장면 이미지) · Claude 호출 · 댓글 규칙 검사 (최대 3회 재작성) |
| `src/drafts.py` | `drafts/<영상ID>.json` 읽기 · 만들기 |
| `src/guard.py` | 운영 규칙(허용 범위 · 영상당 1개 · 하루 상한 · 댓글 규칙) + 기록 `data/history.jsonl` |
| `src/poster.py` | 프로필 열기 → 한 글자씩 입력 → 게시 → 내 댓글 확인 · 링크(`&lc=`) · 캡처 |
| `tests/test_guard.py` | 운영 규칙 테스트 8개 |

## 검증한 것 (2026-10-16)

- **처음부터 끝까지 게시**: 대시보드 API로 본인 테스트 영상에 게시 → 상태가 '프로필 여는 중 → 입력 중 → 내 댓글 확인 중 → 게시 완료' 순으로 바뀜 (약 16초), 댓글 링크(`&lc=`)와 캡처 저장 확인
- **차단**: 같은 영상 두 번째 게시(영상당 1개) · 허용 안 된 채널 링크(Rick Astley 영상) · 링크 아닌 입력 · 규칙 위반 댓글 · 설정 안 된 프로필 → 모두 막히고, 규칙 위반은 기록에 '차단'으로 남음
- **화면**: 1440×900 라이트/다크 캡처, 콘솔 오류 없음
- **초안**: 채널별 3개 · 15개 생성, 15/15 첫 시도에 규칙 통과, $1.01
- **테스트**: pytest 8개 통과

## 안전 규칙 — 코드 위치

| 규칙 | 지키는 방법 |
|---|---|
| 쿠키 · 비밀번호 미접근 | `poster.py`는 프로필 폴더를 Chrome에 넘기기만 하고 파일을 읽지 않음 |
| AI 키 비노출 | `.env`에서만 읽고, `/api/status`는 설정 여부(true/false)만 반환. 로그 출력 없음 |
| 허용된 영상 페이지만 열기 | `guard.check_post` 통과 후 `poster`가 `watch?v=<ID>` 하나만 연다. 링크 입력은 채널 확인 후 허용 채널만 목록에 추가 |
| 댓글 외 동작 없음 | `poster`가 누르는 것은 댓글 창 · 게시 버튼뿐 |
| 외부 전송 없음 | 서버는 127.0.0.1에만 바인딩, 화면 자원은 모두 로컬. 네트워크는 youtube.com과 Anthropic API만 |
| 대시보드 폴더 밖 파일 미열람 | 모든 경로가 프로젝트 루트 기준 (`profiles/`, `drafts/`, `data/`) |
